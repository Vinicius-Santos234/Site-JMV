# Screenshots

Coloque aqui as capturas de tela usadas no README principal.

Sugestão de arquivos (formato `.png` ou `.webp`):

- `hero.png` — topo/hero da home
- `portfolio.png` — slideshow ou grade de portfólio
- `contato.png` — formulário de contato
- `mobile.png` — visão responsiva no celular

Depois, referencie no README da raiz, ex.:

```markdown
![Hero](docs/screenshots/hero.png)
```
